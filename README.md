# The Horror at Highrook 한글패치

Windows Steam판 1.06 / build 18387525용입니다.

[한글패치 다운로드](https://github.com/yoodong724/TheHorrorAtHighrook-ko/releases/latest)

1. 게임을 종료하고 ZIP을 Steam 게임 폴더에 압축 해제합니다.
2. `highrook-ko/install.cmd`를 실행한 뒤 Steam에서 게임을 실행합니다.

제거: 게임 종료 후 `highrook-ko/restore.cmd` 실행. 복원할 때까지 `.highrook-ko-backup`과 `highrook-ko` 폴더를 보관하세요.
